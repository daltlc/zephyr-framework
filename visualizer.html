Auto-Visualizer

Data in. Right component out.

Pass any data shape to Zephyr.agent.visualize() and the framework automatically picks and renders the right component — no configuration needed.

← Back GitHub

Time Series → z-chart

Array of { time, value } auto-renders as a line chart.

KPI Objects → z-stat

Array of { label, value, trend } auto-renders as stat cards.

String Array → z-sortable

Array of strings auto-renders as a drag-to-reorder list.

Object Array → z-data-grid

Array of objects auto-renders as a sortable, filterable data grid with columns derived from keys.
